# ai-news-telegram-bot

Claude·Gemini·ChatGPT의 신규 모델, 프로모션(토큰 증정), 큰 장애를 공식 소스에서 2분마다 확인해 텔레그램으로 한국어 요약과 함께 알려주는 봇을, Claude와 함께 처음부터 만들고 켜 주는 스킬입니다.

[아하모먼트 Friends 소개 페이지에서 먼저 보기 →](https://ahamoment-platform.vercel.app/friends/skill.html?slug=ai-news-telegram-bot)

## 포크해서 내 것으로 만들기

이 저장소는 스킬 하나만 담고 있어서, 포크하면 바로 이 스킬의 사본이 내 계정에 생깁니다.

1. 오른쪽 위의 **Fork** 버튼 → **Create fork**
2. 내 저장소에서 `SKILL.md`와 파일들을 내 업무·환경에 맞게 수정합니다.
3. 수정한 내용으로 아래 설치 방법을 따라 씁니다.

## Claude Code에 설치

터미널에서 아래 명령을 실행하면 이 스킬이 설치됩니다. (포크했다면 주소를 내 저장소로 바꾸세요.)

```bash
git clone https://github.com/sunny1234303-cmd/aha-skill-ai-news-telegram-bot.git ~/.claude/skills/ai-news-telegram-bot
```

설치 후 Claude Code를 새로 열면 `SKILL.md`의 트리거 문구에 반응해 자동으로 실행됩니다.

## 쓰기 전에

- 이 스킬은 만든 사람의 업무 환경을 기준으로 다듬어졌습니다. 내 상황에 맞게 `SKILL.md`를 고쳐 쓰는 것을 권장합니다.
- API 키, `.env`, 개인정보, 고객 데이터는 저장소에 올리지 마세요. 한 번 올리면 지워도 기록에 남습니다.
